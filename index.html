เพิ่มครีเอเตอร์เข้าชีต

การเขียนลงชีตต้องผ่าน Apps Script ที่ติดตั้งในชีตเอง เว็บนี้เป็นหน้าเว็บนิ่งๆ เขียนตรงไม่ได้ — ทำตามขั้นตอนในไฟล์ add-creator.gs แล้วเอา URL กับ token มาใส่

token นี้เขียนลงชีตได้ — ใครได้ไปก็แก้ชีตทีมได้ เก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ได้ส่งไปที่อื่น

AI ช่วยอ่านคำสั่ง

ปกติช่องคำสั่งอ่านด้วยกฎในเบราว์เซอร์ ฟรีและทันที — เปิดอันนี้แล้ว เฉพาะบรรทัดที่กฎอ่านไม่ออก จะถูกส่งไปให้ Claude ช่วยตีความ บรรทัดที่อ่านออกอยู่แล้วไม่ถูกส่ง ไม่เสียเงิน

คีย์นี้เรียกเก็บเงินจากบัญชีคุณ — ใครได้ไปก็ใช้ยิงเงินคุณได้ ออกคีย์แยกสำหรับงานนี้แล้วตั้งลิมิตไว้จะปลอดภัยกว่า
สิ่งที่ถูกส่งออกไป: ข้อความในบรรทัดนั้น + รายชื่อครีเอเตอร์ในระบบ + รายชื่อโปรเจกต์/สถานะ/รูปแบบภาษี เพื่อให้ตอบเป็นค่าที่ใช้ได้จริง
เรท ยอดจ่าย และข้อมูลแถวอื่นไม่ถูกส่ง · ส่งไปที่ api.anthropic.com โดยตรงจากเบราว์เซอร์ ไม่ผ่านเซิร์ฟเวอร์ของเรา
