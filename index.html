เพิ่มครีเอเตอร์เข้าชีต

การเขียนลงชีตต้องผ่าน Apps Script ที่ติดตั้งในชีตเอง เว็บนี้เป็นหน้าเว็บนิ่งๆ เขียนตรงไม่ได้ — ทำตามขั้นตอนในไฟล์ add-creator.gs แล้วเอา URL กับ token มาใส่

token นี้เขียนลงชีตได้ — ใครได้ไปก็แก้ชีตทีมได้ เก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ได้ส่งไปที่อื่น

ความเป็นส่วนตัว

เว็บนี้เก็บของไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่มีเซิร์ฟเวอร์ของเรา: รายการชีต · ลิสต์แนวที่ชอบ · ลิสต์ที่เคยใช้ · คนที่เปิดดูแล้ว · ตะกร้า · เกณฑ์ · token
ทั้งหมดนี้มีชื่อและลิงก์ของคนจริง ถ้าจะส่งเครื่องต่อให้คนอื่นควรล้างก่อน
